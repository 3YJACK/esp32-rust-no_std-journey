# esp32-rust-no_std-journey

This repository documents my personal journey learning Rust no_std on ESP32, from the perspective of a developer with a C embedded background, and also serves as a tutorial for someone with the same background who want to learn Rust no_std.

C语言嵌入式开发者的个人Rust-no_std开发学习记录兼教程，适用于同样有C嵌入式背景想学习rust嵌入式开发的人。

开发环境：VS code | 硬件平台：ESP32S3

学习记录以`./Notes`笔记为主，部分笔记对应的工程源码文件也会放在`./Code`中。
