在终端中输入下列命令进行工程创建：

```
esp-generate
```

根据终端指引选择相应的硬件平台创建工程模板，工程配置建议如下：

**1.核心功能配置**

- **Enable unstable HAL features**：启用 `esp-hal` 中尚不稳定的实验性功能。

  - **建议**：**推荐开启**。ESP32-S3 的许多新特性（如 Wi-Fi、BLE）都依赖于此。API 未来可能变动，但对个人项目影响不大。

- **Enable allocations via the esp-alloc crate**：启用动态内存分配（即在堆上使用 `Vec`、`String` 等）。

  - **建议**：**务必开启**。它是 `wifi` 和 `ble` 等高级功能的基础。即使不立即使用，也建议开启以备后续扩展。

- **Enable Wi-Fi via the esp-radio crate**：启用 Wi-Fi 功能。

  - **建议**：**按需开启**。如果项目需要联网，请开启。

- **Enable BLE via the esp-radio crate (bleps)**：通过 `bleps` 栈启用 BLE（低功耗蓝牙）功能。

  - **建议**：**按需开启**。如果需要 BLE，可以从 `bleps` 开始，它相对更成熟。

- **Enable BLE via the esp-radio crate (embassy-trouble)**：通过 `embassy-trouble` 栈启用 BLE。

  - **建议**：**按需开启**。如果项目已使用 Embassy 框架，选择此选项集成度更高。
  - **注意**：`wifi`、`ble-bleps` 和 `ble-trouble` 都依赖于 `alloc`。Wi-Fi 和 BLE 当前可能无法同时启用。

- **Add embassy framework support**：添加 Embassy 异步框架支持。

  - **建议**：**按需开启，前期学习可先关闭**。Embassy 是 Rust 嵌入式异步编程的主流框架。它能让你用 `async/await` 编写更清晰、高效的并发代码。

- **Enable stack smashing protection**：启用栈溢出保护。

  - **建议**：**推荐开启**。能有效提高系统稳定性。
  - **注意**：这需要 Rust 的 **Nightly 版本**。

**2.开发与调试工具配置**

- **Use probe-rs to flash and monitor instead of espflash**：使用 `probe-rs` 作为烧录和调试工具。

  - **建议**：**按需选择**。`probe-rs` 支持更高级的调试（如断点）；`espflash` 则更简单直接。新手可以先选 `espflash`。

- **Flashing, logging and debugging (probe-rs)**：`probe-rs` 的详细配置。

  - **`defmt`**：高效、轻量级的日志框架，是嵌入式调试的利器。

  - **`panic-rtt-target`**：将`panic`信息通过 RTT 输出，便于调试。

  - **建议**：如果选了 `probe-rs`，**强烈推荐一并开启 `defmt`**。

- **Flashing, logging and debugging (espflash)**：`espflash` 的详细配置。

  - **`log`**：使用标准的 `log` 库打印消息。

  - **`defmt`**：低开销的高效日志框架，通常配合`probe-rs`使用，与`log`只能二选一。

  - **`esp-backtrace`**：提供详细的栈回溯信息。

  - **建议**：如果选了 `espflash`，建议开启 **`esp-backtrace`** 以方便定位崩溃问题。

**3.其他配置选项**

- **Options**：包含一些辅助功能。

  - **`wokwi`**：支持在 Wokwi 模拟器中运行。

  - **`ci`**：添加 GitHub Actions 的持续集成配置。

  - **建议**：`wokwi` 适合快速原型验证；`ci` 适合团队协作，个人项目可按需选择。

- **Optional editor integration**：为特定编辑器生成配置文件。

  - **建议**：选择你使用的编辑器（如 VSCode）即可。

- **Rust toolchain**：指定 Rust 工具链。

  - **建议**：除非有特殊原因，保持默认即可。
